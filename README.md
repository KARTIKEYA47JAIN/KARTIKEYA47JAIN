I'm a DevOps engineer specialising in cloud infrastructure, currently at **Celebal Technologies** where I provision and automate multi-cloud environments across AWS and Azure for enterprise clients.

My day-to-day: Terraform-based infrastructure provisioning, GitLab CI/CD pipelines, Datadog observability (APM, RUM, Synthetic monitoring), Databricks automation, and solving the kind of real integration problems that don't have a Stack Overflow answer.
